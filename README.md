# 한국 산업연관표 실험실

2023년 생산자가격 기본부문 380개 부문, 12개 원자료 시트를 활용하는 학습용 시뮬레이터입니다.

## 기능
- 원본 XLSX 직접 읽기: JSON 변환 없음
- 12개 시트의 행·열 탐색 및 코드·명칭 검색
- 여러 산업의 국내 생산물 최종수요 증가 시나리오
- 생산·수입·부가가치 유발액, 상위 15개 산업, 전체 CSV
- Web Worker에서 Pyodide 실행: Python 초기화/Excel 해석 중 UI 차단 최소화
- 초기화 시 생산·수입·부가가치 계수 관계 검증

## GitHub Pages 게시
1. ZIP을 풀고 **이 README와 index.html이 있는 폴더 내부 내용**을 저장소 최상위에 업로드합니다. 압축파일 자체를 올리지 마세요.
2. `data/io-2023.xlsx` 폴더 구조를 유지합니다.
3. Settings → Pages → Deploy from a branch → main → / (root) → Save.
4. Actions에서 완료를 확인하고 Pages의 주소로 접속합니다.
5. 원자료 탐색 제목 옆의 "기본부문 불러오기" 버튼을 클릭합니다. 준비 완료 확인 → 원자료 탐색 또는 시나리오 추가 → 파급효과 계산.

사용자 사이트와 프로젝트 사이트 모두 상대경로를 사용하므로 지원합니다.

## 로컬 실행
브라우저에서 index.html을 더블클릭하지 마세요. Worker와 fetch 때문에 HTTP 서버가 필요합니다.
```
python -m http.server 8000
```
그다음 http://localhost:8000 에 접속합니다.

## 기술 구성
HTML/CSS/JavaScript, Pyodide 0.27.7, NumPy, openpyxl 3.1.5.
초기 인터넷 연결과 외부 CDN 접근이 필요합니다. 학교 네트워크가 CDN을 차단하면 초기화가 실패할 수 있습니다.
기본 Excel 약 12.3MB 외에도 Python 런타임과 패키지를 다운로드합니다. 저사양 모바일에서는 느리거나 메모리가 부족할 수 있습니다.
파일 선택 기능 없이 기본 Excel만 사용합니다. 기본 Excel은 공개 사이트 파일로 제공됩니다.

## 계산 범위와 한계
- 국내 생산물에 대한 최종수요 증가만 지원합니다. 수입 최종재를 포함한 총지출과 다릅니다.
- 380부문 동일 구조만 지원합니다. 다른 자료를 불러오는 범용 도구가 아닙니다.
- 행: 공급·발생 부문, 열: 수요 증가 부문. `생산유발계수`, `수입유발계수`, `부가가치유발계수`를 직접 적용합니다.
- 총생산은 GDP가 아닙니다. 세 유발액을 더하지 마세요.
- 기타·잔차 등 특수 부문에서 수입+부가가치=수요 항등식을 강제하지 않습니다.
- 가격, 공급 제약, 대체, 시간 경로는 반영하지 않습니다.
- 최종수요 항목별 유발액표는 탐색 기능에서 제공합니다. 개별 산업 수요충격과 혼합해서 사용하지 않습니다.

## 공개 전 필수 작업
공식 자료 출처 URL과 재배포 이용 조건을 확인하여 index.html에 명시하세요. 원본을 공개할 권한이 없으면 기본 Excel을 포함한 이 버전을 공개 배포하지 마세요.

## 검증 범위
제공된 워크북을 대상으로 Python에서 산업 코드, 행렬 크기, 계수 관계 및 테스트 시나리오를 검증했습니다.
실제 Chrome/GitHub Pages에서의 끝단 통합 테스트는 배포 후 필요합니다. 특히 Worker, CDN, CSV와 작은 화면을 점검하세요.

## 화면 수정 사항
데이터 준비 메뉴와 파일 업로드 기능을 제거했습니다. "기본부문 불러오기" 버튼을 클릭해야 Excel 다운로드와 Python 초기화가 시작되며, 완료 후 탐색과 계산이 활성화됩니다. 상단에는 간단한 진행 상태와 계수 검증 결과만 표시합니다.

## 최신 UI 변경
"방법·해석·한계" 섹션 및 메뉴를 제거했습니다. 원자료 탐색 제목 옆의 "기본부문 불러오기" 버튼을 눌러야 기본 자료를 불러옵니다. 접속만으로 Excel 다운로드나 Python 초기화가 시작되지 않습니다. 로딩 중 중복 클릭을 방지하며 실패하면 재시도할 수 있습니다. 계산 가정과 공개 권한 관련 주의사항은 이 README를 참고하세요.
