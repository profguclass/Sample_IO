1. 데이터 준비

첨부된 원본 Excel을 브라우저에서 직접 읽습니다. 서버 Python이나 JSON 변환은 사용하지 않습니다.

다른 연도·분류체계는 지원하지 않습니다. 선택한 파일을 서버에 전송하지 않으며, Python 패키지는 외부 CDN에서 내려받습니다. 처음 준비하는 데 시간이 걸릴 수 있습니다.

데이터를 불러오세요.

2. 원자료 탐색

선택한 행이 각 열과 어떻게 연결되는지 확인합니다. 산업 행뿐 아니라 원표의 합계·분석지표 행도 포함됩니다.

데이터 준비 후 표시됩니다.
열 코드열 이름원자료 값

스크롤하여 전체 열을 볼 수 있습니다. 금액표의 일반 데이터 단위는 백만원입니다. 구성비·유발계수 등 요약 행은 행 명칭을 우선 확인하세요.

3. 국내 생산물 최종수요 증가 시뮬레이션

수입 완제품 구매를 제외한 국내 생산물 최종수요 증가를 입력하세요. 여러 산업의 증가액은 합산됩니다.

1,000백만원 = 10억원. 이번 버전은 양의 수요 증가만 지원합니다.

    4. 방법·해석·한계

    국산투입계수 Ad, 생산유발계수 L, 수입투입계수 Am, 부가가치율 v를 이용합니다.

    L = (I − Ad)⁻¹
생산유발액 = L × 국내 최종수요 증가
수입유발액 = Am × L × 국내 최종수요 증가
부가가치유발액 = diag(v) × L × 국내 최종수요 증가

    워크북에 수록된 세 유발계수표를 사용하며 위 관계와의 일치 여부를 초기화 시 검증합니다. CSV의 수입 행은 수입품 부문, 부가가치 행은 부가가치 발생 부문을 뜻합니다.

    • 생산유발액에는 산업 간 중간거래가 포함되므로 GDP·순편익·기업 매출 증가와 동일시하지 마세요.
    • 생산·수입·부가가치 금액을 서로 더해 총효과로 표시하지 않습니다.
    • 고정 투입구조의 선형 모형이며 가격 변화, 공급 제약, 대체, 시간 경로를 반영하지 않습니다.
    • 산업 합계와 원표의 합계 행을 중복 집계하지 않습니다. 계산은 코드 9000 미만의 확인된 380개 부문만 사용합니다.
    • 표의 특수·잔차 부문에서는 일반적인 부가가치·수입 합계 항등식을 기계적으로 가정하지 않습니다.
